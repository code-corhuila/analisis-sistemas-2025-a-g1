# Instrumentos de Recolección de Información

## Encuesta a Clientes

**Objetivo**: Recopilar información sobre las preferencias y necesidades de los clientes respecto a la aplicación de carrito de compra.

**Formato**:
1. **¿Con qué frecuencia realiza compras en el supermercado del barrio?**
   - [ ] Diariamente
   - [ ] Semanalmente
   - [ ] Mensualmente
   - [ ] Ocasionalmente

2. **¿Qué tipo de sistema preferiría utilizar para realizar sus compras en línea?**
   - [ ] Aplicación móvil
   - [ ] Sitio web
   - [ ] Aplicación de escritorio

3. **¿Qué servicios le gustaría que ofreciera la aplicación de carrito de compra?**
   - [ ] Navegación por catálogo de productos
   - [ ] Agregar y eliminar productos del carrito
   - [ ] Proceso de pago seguro
   - [ ] Registro y autenticación de usuarios
   - [ ] Notificaciones por correo electrónico
   - [ ] Historial de pedidos
   - [ ] Otros: _______________________

4. **¿Qué tan importante es para usted recibir notificaciones sobre el estado de su pedido?**
   - [ ] Muy importante
   - [ ] Importante
   - [ ] Poco importante
   - [ ] No es importante

## Entrevista a Empleados del Supermercado

**Objetivo**: Obtener información sobre las necesidades y expectativas de los empleados respecto a la gestión del inventario y pedidos a través de la aplicación.

**Formato**:
1. **¿Qué funcionalidades considera esenciales para la gestión del inventario de productos?**
   - [ ] Actualización de stock
   - [ ] Visualización de productos
   - [ ] Gestión de categorías
   - [ ] Otros: _______________________

2. **¿Qué tipo de sistema preferiría utilizar para gestionar el inventario y los pedidos?**
   - [ ] Aplicación móvil
   - [ ] Sitio web
   - [ ] Aplicación de escritorio

3. **¿Qué tan importante es para usted poder ver el historial de pedidos de los clientes?**
   - [ ] Muy importante
   - [ ] Importante
   - [ ] Poco importante
   - [ ] No es importante

4. **¿Qué otros servicios le gustaría que ofreciera la aplicación para facilitar su trabajo?**
   - [ ] Notificaciones de nuevos pedidos
   - [ ] Actualización del estado de los pedidos
   - [ ] Reportes de ventas
   - [ ] Otros: _______________________
